# IU Ear Training Simulator

Interval, triad-quality and inversion ear training that runs fully offline.

Open https://populian.github.io/ear-training/ once, then add it to your Home Screen (iPhone/iPad: Safari → Share → Add to Home Screen; Mac: Safari → File → Add to Dock). After that it works with no internet connection. Progress is stored on each device.

Independent practice tool. Not affiliated with or endorsed by Indiana University.

Grand piano samples: Salamander Grand Piano V3 by Alexander Holm, CC BY 3.0 (see samples/CREDITS.txt).
